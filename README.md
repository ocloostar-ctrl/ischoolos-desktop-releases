# iSchoolOS for Windows

Official Windows downloads and desktop update metadata for [iSchoolOS](https://ischoolos.com).

Use the Setup installer for an everyday Windows PC, or the Portable EXE for use without installation. Download the latest release from this repository's Releases page. Installed apps from version 1.0.1 onward check for desktop updates automatically. Portable apps notify users to download the new EXE and retain their iSchoolOS Data folder.

School accounts, records and credentials remain on the school service. These downloads do not contain a school database or server keys. The application source remains private.

Current packages are unsigned. Windows may display an unknown-publisher notice. General work requires the school service; the EXE alone does not enable full offline synchronization.
